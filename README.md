# sublea
A platform for students to post and find subleases.




## How to Run Locally, Docker Implementation
### Correct Directory
Move to sublea directory: cd sublea
Verify you see docker-compose.yaml: ls

### Docker Compose run
Docker compose build
docker compose up -d
